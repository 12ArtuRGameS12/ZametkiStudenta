Для скачивания файлов сайта вам необходимо нажать на зеленую
кнопку `code` и выбрать пункт `Download ZIP`. После этого
скачаеться весь репозиторий сайта, но вам потребуеться только
папка `content`. После этого вы можете воспользоваться
приложением `obsidian` для удобного чтения всех файлов офлайн.
