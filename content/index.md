# Внеси свой вклад

Каждый может принести свой вклад в проект:
- Помочь проверить заметки, требующие проверки (см. [[Проверено ли.base]]).
- Добавить свои заметки или шпаргалки для лучшего понимания и запоминания материала.
- Загружать PDF файлы, оцифровывать их в md формат и вытаскивать из него все рисунки. Возможно, оцифровать графики для более точного их считывания значений.
- Добавить свои желания. Например, какие бы приложения пригодились бы во время учёбы или какую бы информацию хотели бы видеть.

> [!warning] Внимание
> Для помощи в проекте нужно изучить работу с git и с obsidian или обратиться к знающему человеку.

Правила работы в репозитории:
- Каждый файл должен иметь свойство "проверено".
- Любой не текстовый файл (pdf, фото) должен быть связан с md файлом для его описания.
